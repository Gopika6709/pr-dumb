# HARDWARE IMPLEMENTATION
This is a project to write an Api layer for eeprom and gyro using I2C communication protocol.

## TASK OVERVIEW
- Write a GPIO layer to control the registers assosiated with the gpio pins in the stm32 board
- Write a I2C laye that handles communication using this GPIO layer
- Write an eeprom or gyro layer to use this i2c communication so as to communicate b/w board and device 
- Provide the user with a list of API's they can use
